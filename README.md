# Dear Angel — Birthday Scrapbook

A responsive, one-page birthday scrapbook made with HTML, CSS and JavaScript. Includes a 10-photo gallery, three interactive memory letters, a personal letter, reason cards, cake cutting, candle blowing, and accessible modal close controls.

## Publish with GitHub Pages

1. Upload the **contents** of this folder to the root of your GitHub repository.
2. Confirm that `index.html` is in the repository root (not inside another nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site.

## Add your photos

The gallery expects these exact filenames inside `images/`:
`photo1.jpeg` through `photo10.jpeg`.

Keep the filenames and capitalization exactly as shown.

## Interactions included\n\n- Open the gift and navigate between sections.\n- Open any gallery photo in a lightbox; close it with the × button, Escape, or a background click.\n- Open all three memory letters and the personal letter.\n- Reveal the five reason cards and the hidden note.\n- Cut the cake and blow out the candles.\n- Use the mobile navigation and replay button.\n\n## Add background music (optional)

Place an MP3 file named `birthday-song.mp3` inside `music/`.
The browser starts playback only after the visitor interacts with the page. If no music file is present, the scrapbook still works.

## Local preview

Open `index.html` in a modern browser. PHP/XAMPP is no longer required.

## Notes

This is a static HTML/CSS/JavaScript site compatible with GitHub Pages. Google Fonts, Font Awesome and optional GSAP enhancements load from CDNs.
